# Start as a single-user product with an ownership boundary

**Status**: superseded by [ADR-0005](./0005-small-team-accounts-with-owner-scoped-data.md)

This was the original scope decision: start with one user's ledger and retain an ownership/organization boundary. The current scope now adds a small number of administrator-created member accounts; the ownership boundary remains, while the single-user-only UI assumption is superseded by ADR-0005.
